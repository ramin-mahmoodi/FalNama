## معرفی پروژه

**فال‌نامه (FalNama)** یک وب‌اپلیکیشن سبک، مستقل و چشم‌نواز است که سنت دیرین تفأل به دیوان خواجه شیراز را با فناوری‌های مدرن وب پیوند می‌زند. این پروژه با شبیه‌سازی هندسی یک دیوان چرمی سه‌بعدی، افکت‌های ورق‌زدن فیزیکی، خوشنویسی نستعلیق و پخش دکلمه صوتی تمامی ۴۹۵ غزل دیوان حافظ، تجربه‌ای زنده و دلنشین از تفأل را برای مخاطب به ارمغان می‌آورد.

تمامی اجزای پروژه بدون نیاز به هیچ کتابخانه سنگین، ابزار بیلد یا فریم‌ورک خارجی (Pure Vanilla JS, Modern CSS و HTML5) ساخته شده‌اند.

---

## ویژگی‌های کلیدی

- 📖 **شبیه‌سازی سه‌بعدی کتاب:** مدل‌سازی دیوان حافظ با پرسپکتیو سه‌بعدی واقعی، عطف و ورق‌های چندلایه، بافت چرم طبیعی و حاشیه‌های طلاکوب.
- 📜 **دیوان کامل (۴۹۵ غزل):** شامل متن کامل ابیات، تعبیر اختصاصی و نتیجه تفأل برگرفته از پایگاه داده معتبر حافظ شیرازی.
- 🎙️ **دکلمه صوتی تمام غزل‌ها:** همراه با پلیر اختصاصی، امواج تعاملی صوتی (Waveform) با قابلیت جهش و پیمایش زمان صوت.
- 🎨 **تولید خودکار کارت فال (Shareable Card):** قابلیت تولید یک کارت گرافیکی باکیفیت و چشم‌نواز از ابیات فال با HTML5 Canvas برای اشتراک‌گذاری در شبکه‌های اجتماعی یا دانلود مستقیم.
- 🗂️ **بایگانی و تاریخچه فال‌ها:** ثبت فال‌های گرفته‌شده در حافظه محلی مرورگر (Local Storage) با دسته‌بندی زمانی هوشمند (*امروز*، *دیروز*، *این هفته*، *قدیمی‌تر*) و ژست حرکتی کشیدن برای حذف (*Swipe to Delete*).
- 💖 **علاقه‌مندی‌ها:** امکان برگزیدن فال‌های محبوب جهت دسترسی سریع در بخش تاریخچه.
- ✒️ **خوشنویسی اصیل:** بهره‌گیری از خط زیبای نستعلیق (`Noto Nastaliq Urdu` و فونت بهینه‌شده محلی `IranNastaliq`) همراه با تایپوگرافی لاله‌زار و وزیرمتن.
- 📱 **طراحی واکنش‌گرا (Responsive):** تجربه کاربری روان مشابه اپلیکیشن‌های موبایل (PWA-like) در تمام ابعاد صفحه‌نمایش.

## هویت بصری و طراحی رترو کرافت

طراحی رابط کاربری پروژه بر پایه هویت کاغذ کرافت دست‌ساز، پالت رنگ‌های خاکی گرم (شنی، حنایی، لاجوردی و قرمز روناسی) و نقش‌مایه‌های تذهیب سنتی شکل گرفته است:

- **پس‌زمینه کرافت:** بافت شنی و خطوط انتزاعی منحنی که حس ورق‌زدن نسخه‌ای خطی و کهن را القا می‌کند.
- **جلد دیوان:** شبیه‌سازی بافت چرم طبیعی با فیلترهای نوری SVG و ضرب طلاکوب تذهیب.
- **تایپوگرافی اصیل:** ترکیب خط نستعلیق برای ابیات غزل و تیترهای برجسته لاله‌زار با خوانایی بالای فونت وزیرمتن.

## معماری کتاب سه‌بعدی

پویانمایی دیوان حافظ بر پایه معماری خالص `transform-style: preserve-3d` در CSS بنا شده است:

```
[ stage ]
  └── [ persp ]
        └── [ bob ]  (شناوری پیوسته در فضا)
              └── [ rig ]  (کنترل زاویه دوربین و زوم روی صفحه منتخب)
                    └── [ book ]
                          ├── [ spine ]  (عطف کتاب با برجستگی‌ها و طلاکوب)
                          ├── [ leaf cover ]  (جلد چرمی دیوان)
                          ├── [ leaf L0 ... L8 ]  (صفحات میانی در حال ورق خوردن)
                          └── [ leaf bc ]  (پشت جلد دیوان)
```

هنگام لمس کتاب:
1. کتاب زاویه گرفته و رو به مخاطب قرار می‌گیرد (`rig.prep`).
2. جلد چرمی گشوده می‌شود و صفحات با تأخیرهای دینامیک و فیزیکی به نوبت ورق می‌خورند (`leaf.flipped`).
3. صفحهٔ برگزیده مشخص شده و دوربین بر روی شعر زوم می‌کند (`rig.zoom`).
4. فال با همراهی دکلمه، شرح تعبیر و نتیجه نمایان می‌گردد.

## پخش صوتی دکلمه‌ها

هر غزل دارای فایل صوتی اختصاصی با نام `audio/{n}.mp3` است. ویژگی‌های پلیر صوتی:
- نمایش امواج صوتی تعاملی (۳۴ ستون اکولایزر)
- امکان کلیک یا لمس مستقیم روی موج برای جلو و عقب بردن زمان
- ثبت زمان سپری‌شده و مدت کل
- سیستم رزرو هوشمند (Web Speech Synthesis / Web Audio Synth) در شرایط نبود اتصال شبکه

---

## سیستم ساخت و ذخیره کارت فال

با فشردن دکمه اشتراک‌گذاری در صفحه فال:
1. یک بوم `HTML5 Canvas` با ابعاد استاندارد و بهینه ۱۰۸۰×۱۵۶۰ پیکسل تشکیل می‌شود.
2. بافت کرافت، کادربندی هندسی، نشان تذهیب، عنوان غزل و ابیات با خط نستعلیق روی بوم رسم می‌شوند.
3. در صورت پشتیبانی مرورگر از Web Share API، پنجره هم‌رسانی سیستم‌عامل باز شده و در غیر این صورت تصویر با فرمت PNG ذخیره می‌گردد.

## تاریخچه هوشمند با Swipe to Delete

- تمامی فال‌های خوانده‌شده به همراه تاریخ و نشان علاقه‌مندی در `localStorage` نگهداری می‌شوند.
- آیتم‌ها به‌صورت خودکار بر اساس فاصله زمانی دسته‌بندی می‌شوند.
- با کشیدن انگشت یا ماوس روی هر آیتم به طرفین (Swipe)، آیتم با انیمیشن روان حذف می‌شود.

## راهنمای اجرای محلی

از آنجا که پروژه کاملاً مستقل و Vanilla است، بدون نیاز به ابزارهای ساخت یا نصب پکیج می‌توانید آن را اجرا کنید:

### ۱. کلون کردن مخزن:
```bash
git clone https://github.com/ramin-mahmoodi/FalNama.git
cd FalNama
```

### ۲. اجرا با یک وب‌سرور محلی:
برای دسترسی مرورگر به فایل‌های صوتی محلی، اجرای یک سرور سبک توصیه می‌شود:

**با پایتون (Python 3):**
```bash
python -m http.server 8000
```
سپس در مرورگر خود آدرس `http://localhost:8000` را باز کنید.

**با افزونه‌های Live Server یا Node:**
```bash
npx serve .
```
